# Sample files

Fictional files for trying Local Delegate. Nothing in them is real.

| File | Try saying |
|---|---|
| `sample-report.md` | *"Digest examples/sample-report.md locally: decisions, risks and dates."* |
| `sample-pytest-log.txt` | *"Triage the failures in examples/sample-pytest-log.txt with the local model."* |
| `sample-letter-fr.txt` | *"Summarize examples/sample-letter-fr.txt locally: what do I need to do, and by when?"* or *"Translate it into English and keep it on my computer."* |

Open Claude Code in this repository's folder, or give the full path, so that the files are inside
the allowed folders (your user folder by default).
